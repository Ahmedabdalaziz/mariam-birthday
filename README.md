# 🎂 مفاجأة عيد ميلاد مريام — Mariam Birthday Wall

الموقع بسيط وواضح، وبيشتغل من غير سيرفر خاص:

- **صفحة الأصحاب والحبايب** (`friends.html`): بيكتبوا الاسم + أول تعامل/ذكرى + تهنئة + مقياس الحب (❤️) + صورة اختيارية. الرسالة بتتسجل في قاعدة بيانات Supabase على طول.
- **صفحة مريام** (`wall.html`): مقفولة بعدّاد تنازلي لحد الساعة **12 بالليل يوم 6 نوفمبر 2026**. لما العد يخلص، بتفتح لوحدها بعرض جميل وكونفيتي 🎉، وبتطلع فيها كل الرسايل والصور باسم اللي كتبها. وأي رسالة جديدة بتظهر فيها على طول (Realtime).

التصميم على أحدث تريندات 2026: كروت زجاجية (Glassmorphism)، خلفية ألوان متدرجة متحركة (Aurora)، ألوان ناعمة تناسب المناسبة (فوشيا / بنفسجي / خوخي)، وخطوط عربية لطيفة.

---

## خطوات التشغيل بالترتيب

### 1) خطوة Supabase (مرة واحدة)
أنت عملت مشروع Supabase، ومعلومات الربط (URL + Key) موجودة فعلًا في `js/config.js`.

اللي باقي: تشغيل سكربت الإعداد مرة واحدة:
1. من القايمة الشمال في Supabase افتح **SQL Editor**.
2. افتح ملف `supabase-setup.sql` اللي في المشروع، انسخ محتواه كله، الصقه، واضغط **Run**.
3. لو ظهر Success — تمام، الجدول والصور والصلاحيات كلها جاهزة. ✅

### 2) رفع المشروع على GitHub
اعمل Repository جديد باسم `mariam-birthday`، وبعدين من جوه فولدر المشروع:

```bash
git init
git add .
git commit -m "إطلاق موقع عيد ميلاد مريام"
git branch -M main
git remote add origin https://github.com/USERNAME/mariam-birthday.git
git push -u origin main
```
(غيّر USERNAME لحسابك)

### 3) تشغيل GitHub Pages (مرة واحدة)
1. من صفحة الـ Repository: **Settings → Pages → Build and deployment → Source** واختار **GitHub Actions**.
2. أول مرة تعمل Push، ملف `.github/workflows/deploy.yml` الموجود في المشروع هينشر الموقع تلقائي.
3. بعد ما الـ Workflow يخلص (علامة ✅ خضرا)، الرابط هيكون: `https://USERNAME.github.io/mariam-birthday/`

### 4) التجريب
1. افتح `friends.html` من اللينك المباشر، واكتب رسالة تجريبية بصورة.
2. لو وصلت تمام، يعني كل حاجة شغالة. لو ظهر تنبيه "الربط لسه مضبوطش"، راجع الخطوة 1.

### 5) عمل Release
- من GitHub: **Releases → Draft a new release → Choose a tag**، اكتب `v1.0.0`، واضغط **Publish release**.
- أو من التيرمينال:
```bash
git tag v1.0.0 -m "عيد ميلاد سعيد يا مريام"
git push origin v1.0.0
```

## فتح الجدار قبل 12 بالليل (اختياري)
لو حبيت تخلي مريام تتصفح بدري: افتح `js/config.js` واكتب كلمة سر في `UNLOCK_CODE`. هتظهر عند مريام خانة كلمة سر 🔑، ولما تكتبيها صح السكرول يفتح.

## ملاحظات

- **العدّاد**: بيقرا الساعة المحلية لكل جهاز. لو ساعة الجهاز مش مضبوطة، ممكن يظهر فرق ثواني بسيط.
- **رسالة إزعاج؟**: تقدر تمسحها أو تعدلها من **Table Editor** في Supabase (جدول `birthday_messages`).
- **الأمان**: النصوص بتتصفى قبل عرضها في الصفحة (حماية من XSS)، والصلاحيات محدودة زي ما سكربت SQL حاططها.
- **الصورة**: بتتضغط تلقائي قبل الرفع عشان الموقع يفضل سريع.
